# CoreMedia KIO Co-Pilot Backend

![GitHub latest release](https://img.shields.io/github/v/release/coremedia-contributions/kio-backend)
<img src="https://img.shields.io/badge/CMCC%20Version->=2406.1.1-blue.svg">

The CoreMedia KIO Co-Pilot Backend will be delivered as docker image.

To pull the latest KIO Co-Pilot Backend image use your CoreMedia credentials to log in to the 
CoreMedia Container Registry.

Available release tags and release notes can be found in this repository below
[Releases](https://github.com/coremedia-contributions/kio-backend/releases).

```
docker login container-registry.coremedia.com
docker pull container-registry.coremedia.com/coremedia/kio-editorial-backend:RELEASE_TAG
```

For detailed documentation and installation instructions for KIO Co-Pilot, see: 
https://documentation.coremedia.com/how-to-guides/KIO

## Requirements

- CoreMedia Content Cloud **v12 2406.1.1** or later
